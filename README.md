# project_2_Game-content-reputation-analysis

## 프로젝트 개요
- 이 프로젝트는 유튜브 댓글을 크롤링하여 게임 콘텐츠에 대한 평판을 분석하고, 이를 기반으로 기획 방향을 도출하는 것을 목표로 한다. 
- 크롤링된 댓글 데이터를 활용하여 자연어 처리 및 토픽 모델링을 수행하며, 게임 콘텐츠의 반응을 즉각적으로 파악할 수 있을 을기대한다.

## 주제 선정 이유
- 시장 환경 변화 : [확률형 아이템 정보공개] 법적 의무화에 따라 게임 시장의 환경이 변화하고 있으며, 이러한 변화를 반영한 콘텐츠 기획이 필요하다.
- 유튜브 댓글의 가치 : 유튜브 댓글은 장기간 기록되며, 불특정 다수에게 노출되는 특성을 가지고 있어 사용자 반응을 분석하기에 적합하다.
- 데이터 활용 : 유튜브 데이터를 적극 활용하여, 게임 콘텐츠에 대한 실질적인 사용자 반응을 파악할 수 있는 방안을 고안한다.

## 사용 언어 및 도구
- Python :  VScode, Google Colab
- 크롤링 모듈 : google-api-python-client, google-auth-httplib2
- 자연어 처리 : konlpy, Mecab, gensim
- 시각화 : matplotlib, pyLDAvis, Google Looker Studio

## 프로젝트 진행 단계
1. 데이터 수집: YouTube API를 통해 각 게임과 관련된 댓글을 수집
2. 데이터 전처리: 불필요한 문자 제거, 형태소 분석(Mecab) 등을 통해 텍스트 정제
3. 자연어 처리: 감정 분석을 통해 댓글의 긍정, 부정, 중립 감정을 분류
4. LDA 토픽 모델링: 댓글의 주요 주제를 파악하기 위해 LDA 모델을 사용하여 토큰화 및 토픽 모델링 수행
5. 시각화: 결과를 pyLDAvis, Google Looker Studio, PPT 등을 활용해 시각화

## 감정 분석 (Sentiment Analysis)
- 전문가 분석 : 금융뉴스 분석 모델을 기반으로 5000개의 무작위 댓글 샘플을 학습시켜 분석
  - [GitHub Repository](https://github.com/ukairia777/finance_sentiment_corpus)
- GPT-4 : 5000개의 무작위 댓글 샘플링 후, GPT-4 모델을 학습시켜 댓글 분석
- CHOI-Me : 5000개의 무작위 댓글 샘플링 후, 해당 모델을 학습시켜 댓글 분석

## 시각화
- pyLDAvis : LDA 토픽 모델링 결과를 시각적으로 표현
- Google Looker Studio : 분석 결과를 대시보드 형태로 시각화
- PPT : 분석 결과를 프레젠테이션 자료로 정리
